# Visual Style Specification v0.1

## Overview

Shmup Rogue's visual identity draws from late-1980s arcade sci-fi: R-Type, Gradius, and the films that inspired them—Alien, Aliens, Blade Runner. The universe is dangerous, strange, and varied—from sterile corporate stations to pulsing organic nightmares.

## Environment Framework

Environments are generated by combining three axes:

### Origin

What made this place?

| Value             | Description                                   | Examples                                             |
| ----------------- | --------------------------------------------- | ---------------------------------------------------- |
| **Human**   | Built by humans or human-derived civilization | Stations, cities, ships, factories                   |
| **Alien**   | Built by non-human intelligence               | Temples, tombs, structures with unknowable purpose   |
| **Natural** | Not built—geological, astronomical           | Caves, asteroid fields, planetary surfaces           |
| **Organic** | Grown, living, biological                     | Hives, interiors of organisms, coral-like structures |

### Age

How long has it existed? Is it still in use?

| Value                | Description                          | Examples                                             |
| -------------------- | ------------------------------------ | ---------------------------------------------------- |
| **Active**     | Currently inhabited/operational      | Populated stations, living cities, functioning ships |
| **Abandoned**  | Recently vacated, still recognizable | Derelict ships, ghost stations, empty outposts       |
| **Ancient**    | Old beyond memory, purpose unclear   | Alien ruins, primordial caves, time-worn structures  |
| **Primordial** | Existed before civilization          | Natural caverns, asteroid interiors, planetary cores |

### State

What condition is it in?

| Value               | Description                      | Examples                                                  |
| ------------------- | -------------------------------- | --------------------------------------------------------- |
| **Pristine**  | Clean, functional, maintained    | Corporate stations, new ships, sterile labs               |
| **Decayed**   | Worn, rusted, degraded by time   | Industrial zones, old cities, salvage yards               |
| **Corrupted** | Infected, overtaken, transformed | Biomechanical fusion, infested stations, spreading growth |

## Visual Rules

### Pixel Art

- **Resolution:** TBD
- **Minimum grain size:** 2×2 pixels (1×1 invisible through CRT shader)
- **Palette:** Per-environment, drawn from 80s arcade sensibilities

### CRT Shader

Simulates arcade monitor characteristics:

- Scanlines
- Color bleed/smearing (reason for 2×2 minimum grain)
- Subtle curvature (optional)
- Bloom on bright elements

### Parallax Backgrounds

Multi-layer scrolling backgrounds create depth and speed:

- Distant layer: stars, nebulae, planetary bodies
- Mid layers: environmental context (city skylines, asteroid fields, organic structures)
- Near layer: gameplay space

Fast parallax is essential to the feeling of velocity—even when player movement is slow, the background sells speed.

## Color Direction

*(To be developed per environment type)*

General principles:

- Each environment type has a dominant palette
- Corruption introduces organic greens, purples, reds into otherwise sterile palettes
- Alien structures use colors that feel "wrong"—combinations humans wouldn't choose
- Player ship and projectiles must read clearly against all backgrounds
