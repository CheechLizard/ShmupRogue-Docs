# Glossary

| Term | Definition |
|------|------------|
| **Arena** | Free-roaming stage for resource gathering and combat. Wraps at edges (toroidal). |
| **Corridor** | Linear stage with spine-and-branch structure leading to boss. |
| **Level** | One complete loop: Arena → Corridor → Boss → Store. |
| **Module** | Component in the weapon system: BATTERY, TRIGGER, REPEATER, BARREL, STRIKER, PAYLOAD. |
| **Portal** | Player-constructed passage between stages. Persists for the run. |
| **Segment** | Authored building block used to construct stages. |
| **Stage** | One part of a Level (Arena, Corridor, Boss, or Store). |
| **Strike** | A single weapon discharge flowing through the module graph. |
| **Toroidal** | Space that wraps at edges—exit right, enter left. Creates feeling of infinite space. |
